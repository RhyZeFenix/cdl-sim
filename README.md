# CDL Season Sim

Call of Duty League season simulator for CDL 2024 (MWIII), 2025 (BO6) and 2026 (BO7).

**Play it:** https://rhyzefenix.github.io/cdl-sim/. Every push to `main` re-runs the tests and redeploys the site (`.github/workflows/pages.yml`).

## Layout

- `data/seasons/{2024,2025,2026}.json`: teams, map pools, stages (qualifier weeks, Minors, Majors), Champs, points, tiebreakers, real results, sources, and an `unverified` list
- `data/veto.json`: veto procedures as step lists (ban / pick / remaining / side), referenced by id from each season
- `data/rosters/{year}.json`: per-event starting lineups (with source URLs) and player ratings, generated by `scripts/build-rosters.ts`
- `src/engine`: pure TypeScript with no UI imports. `src/engine/data` has the zod schemas, the loader with cross-file checks, and the map-pool lookup
- `src/ui`: React front end (placeholder until milestone 4)
- `tests`: Vitest

## Commands

```bash
npm test             # unit tests
npm run typecheck
npm run data:check   # validate all data and print a per-season summary
npm run series -- --season 2026 --a optic-texas --b faze-vegas --phase champs --seed demo [--bo 9] [--box]
npm run calibrate -- --n 10000   # score histograms, kills, FB conversion, clutch rate per mode
npm run season -- --season 2026 --seed demo [--randomized] [--quiet]
npm run season -- --all          # time all three seasons
npm run parity -- --season 2026 --n 20   # who wins events/Champs across many seeds
npm run dev          # UI dev server
```

`--phase` is `champs`, `major:<stage>`, `minor:<stage>` or `quals:<stage>:<week>` and selects the map pool.

## Simulation

- `src/engine/rng.ts`: seeded RNG. `fork(label)` gives independent streams, so the same seed always replays the same season.
- `src/engine/sim/arena.ts`: the gunfight core. Every kill, death and damage number comes from a duel.
- `src/engine/sim/modes/*`: Hardpoint (hill by hill), SnD (round by round: plants, defuses, clutches), Control (rounds with a 30-life pool), Overload (possessions, halves, sudden death).
- `src/engine/sim/boxscore.ts`: box scores and map scores are recomputed from events only.
- `src/engine/sim/veto.ts`: runs any `data/veto.json` procedure. Teams decide through a `Chooser`: the AI by default, or the UI in GM mode.
- `src/engine/sim/tuning.ts`: every calibration knob.

## UI (`npm run dev`, then open http://localhost:5173)

- **Header:** pick a season, seed and Historical/Randomized ratings, then "New season". Sim week, Sim stage and Sim season run the season. In Watch speed, the headline match of each sim (the week's first match, or an event's final) opens and plays back live. Export/Import saves and loads the whole season as JSON. **Champs only** skips the regular season and plays Champs from that year's real seeds (2026 also starts from the real final points).
- **Schedule:** stage by stage, week by week, with the map pool for each week; Minors and Majors appear inline with their real results for comparison.
- **Standings:** the CDL points table (Champs cut line) and each stage's qualifier table, using the season's tiebreakers.
- **Brackets:** every Minor, Major and Champs, including play-ins and Pro-Am groups, plus placements and points awarded.
- **Match page:** veto board, map cards, per-map and series box scores, play-by-play, and Watch (play/pause, 1×/4×/16×, next beat, scrubber, live kill feed). Online matches have no stored log; opening one replays it exactly from the seed.
- **Summary:** champion and Champs MVP vs the real result, points race chart (up to 3 highlighted teams), event winners, K/D leaders, and a cumulative points table.

## GM mode

Choose **GM** in the header, pick a team, then start a new season.

- **My Team:** set your four starters from a 4–6 player roster, and see ratings, results and your move log. "Auto-veto my matches" hands your vetoes to the AI.
- **Roster moves:** sign and release only in preseason and between stages (after a Major, before the next stage's qualifiers). Free agents are every player in the season's data who isn't starting for another team on the next match date. If you sign a player an AI team would field later, that team plays its next available player, or a replacement-level one (72 across the board).
- **Vetoes:** when the sim reaches one of your series it stops (mid-week or mid-bracket) and opens the veto screen:
  1. Lock in a lineup, and choose Team A or B if you're the higher seed.
  2. Answer your bans, picks and sides while the opponent's AI answers instantly ("AI finish" completes the rest).
  3. Play the series. The sim then carries on with the week, stage or season you started.
- **Determinism:** each series stores its lineups and your veto answers, so GM seasons replay exactly and save/load mid-season.

Engine API (`src/engine/season/season.ts`): `advance` returns `undefined` and sets `state.pending` at a GM series. `gmVetoSession` starts the interactive veto (a `VetoSession` that only waits on your decisions) and `submitGmVeto` stores it. The next `advance` resumes the step. Roster functions: `gmSign`, `gmRelease`, `gmSetStarters`, `gmSetAutoVeto`, `freeAgents`, `gmCanMakeMoves`.

## Season pipeline

- `src/engine/season/schedule.ts`: seeded round-robin slices; every team plays exactly the stage's match count with no repeat opponents.
- `src/engine/season/standings.ts`: standings with the season's tiebreaker order. Head-to-head counts only games among the teams still tied; a seeded coin flip is the last resort.
- `src/engine/season/bracket.ts`: every format is a list of match definitions (slots point at a seed or at the winner/loser of an earlier match). It covers the 12-team double elimination (seeds 9–12 start in Losers R1), the 8-team Champs bracket, Minors (12-team single elimination with 4 byes), the 2026 Major II play-in, and the 2026 Pro-Am GSL groups feeding the playoff.
- `src/engine/season/season.ts`: `SeasonState` is plain JSON, so save/load is `JSON.stringify`/`parse`. `advance` runs one step (a qualifier week or an event), `advanceStage` runs to the next Major, `advanceSeason` runs to the end. Full event logs are kept for LAN events and the GM team; any other series is rebuilt exactly with `replaySeries`.

### Bracket assumptions (not verified against official brackets)

- In Losers R1 of a 12-team Major, the loser of the 1v8 match plays seed 12, 4v5 plays 11, 2v7 plays 10, and 3v6 plays 9.
- Winners-semifinal losers drop crosswise to avoid an immediate rematch.
- Pro-Am group draw: A = 1/8/9/16, B = 2/7/10/15, C = 3/6/11/14, D = 4/5/12/13. Group winners meet another group's runner-up in the playoff.
- Ties in CDL points are broken by season series wins, then map differential (no official rule found).

## Player ratings and where they come from

- **Stats source:** the Call of Duty Esports Wiki's Cargo table `PlayerStats` (one row per player per map), downloaded by `npx tsx scripts/fetch-stats.ts` into `data/stats/{year}.raw.json`. The script makes two aggregate queries per season, spaced out and backing off on rate limits. The content is **CC BY-SA 3.0** (cod-esports.fandom.com contributors). Attribution is kept in each file, and derived files fall under the same license.
- **Breaking Point isn't used:** its terms say all use of its content requires written consent, and its API is by request.
- **Stat-based ratings:** `scripts/stat-ratings.ts` standardizes each stat against the season's regulars (15+ maps) and shrinks small samples toward average.

  | Rating | Built from |
  |---|---|
  | slaying | overall K/D |
  | hp_obj | Hardpoint K/D 65% + hill time per map 35% |
  | snd_iq | SnD K/D 50% + net opening kills 30% + plants/defuses 20% (where tracked) |
  | third_mode | Control or Overload K/D 75% + captures 25% |
  | clutch | a mild SnD K/D proxy (no clutch stat is published) |
  | consistency | still a placeholder (needs per-map data) |

- **Team results blend:** each rating is 70% stat-based and 30% from team placements, so a good slayer on a losing team isn't over-rated.
- **Map modifiers:** each team's win rate on a map relative to its average in that mode, shrunk for small samples and capped at ±0.03 skill. The AI veto uses them, and so does the sim.
- **Lineup timelines:** a team gets a snapshot from each stage's qualifiers (its four most-played players there, from `data/stats/{year}.lineups.json`) and from each Major/Champs participant list (dated from the event). This catches changes at events a team missed; for example, 2026 Cloud9 switched lineups for Stage 2, but missed the 10-team Major II.
- **Rebuilding rosters:** `npx tsx scripts/build-rosters.ts` reads the committed event pages in `data/sources/fandom/` plus the stats. Players who only appear in qualifier stats join their team's bench. Each player records `ratingSource` (`stats` or `placeholder`) and a stat line, which My Team shows as K/D with "est." for placeholders.

## Backtest

`npm run backtest -- --n 200` simulates each season 200 times with Historical ratings, compares the results with what really happened, and writes [docs/backtest.md](docs/backtest.md). It checks:

- **Event winners:** the win probability the sim gives each real Major/Champs winner, and the rank correlation of placements.
- **Team strength:** each team's real map win % per mode against the simulated one: correlation, plus spread with the real data's sampling noise removed.
- **Scorelines:** real map score distributions from the committed Liquipedia pages, compared with simulated ones.
- **CDL points:** real points rebuilt from the series results (`npx tsx scripts/fetch-results.ts`) and real Major placements.

`--tune key=value,...` overrides any `TUNING` value for a sweep, for example `--tune duelK=2.4,modeDuelScale.snd=2,overload.gapSecs=6:10`. The current `duelK`, `modeDuelScale`, `catchUp` and Overload pacing were chosen this way.

Per-event form (`eventFormSd`, a seeded hot/cold value per team for each qualifier week and event) was tested at 200 seeds and left **off**. At 0.025 it lifts the real 2026 upsets (Paris's Major I win goes from 2.5% to about 10%), but mean event log loss gets worse, from 1.60 to 1.66. That's because the 2025 favorites mostly did win, and form also flattens team spread. Turn it on with `--tune eventFormSd=0.025` if you want chaos.

Overload note: the real 2026 map scores have 4–3 and 3–2 as the most common results, as the original brief said. But nearly half of the winners scored 5 or more, so the sim now produces more captures per map than the brief's "winner on 2–5" target.

## Data notes

- Every JSON file is validated on load. Bad data throws a `DataError` listing every problem.
- Veto bans are skipped when they would leave a mode with fewer maps than the series needs (`skipBanIfInsufficient`). This handles 2025's two-map Control pool and the Bo9 SnD maps without special cases.
- Player ratings come from season stats where available (see above). Roles default to `flex`: the stats don't say who plays AR or SMG.
