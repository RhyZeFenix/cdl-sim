# CDL Season Sim

Call of Duty League season simulator for CDL 2024 (MWIII), 2025 (BO6) and 2026 (BO7).

**Play it:** https://rhyzefenix.github.io/cdl-sim/. Every push to `main` re-runs the tests and redeploys the site (`.github/workflows/pages.yml`).

## Layout

- `data/seasons/{2024,2025,2026}.json`: teams, map pools, stages (qualifier weeks, Minors, Majors), Champs, points, tiebreakers, real results, sources, and an `unverified` list
- `data/veto.json`: veto procedures as step lists (ban / pick / remaining / side), referenced by id from each season
- `data/rosters/{year}.json`: per-event starting lineups (with source URLs) and player ratings, generated by `scripts/build-rosters.ts`
- `src/engine`: pure TypeScript with no UI imports. `src/engine/data` has the zod schemas, the loader with cross-file checks, and the map-pool lookup
- `src/ui`: React front end. Simulation runs in a Web Worker (`src/ui/simWorker.ts`) so the page stays responsive, falling back to the main thread if workers are unavailable (placeholder until milestone 4)
- `tests`: Vitest

## Commands

```bash
npm test             # unit tests
npm run typecheck
npm run data:check   # validate all data and print a per-season summary
npm run series -- --season 2026 --a optic-texas --b faze-vegas --phase champs --seed demo [--bo 9] [--box]
npm run calibrate -- --n 10000   # score histograms, kills, FB conversion, clutch rate per mode
npm run season -- --season 2026 --seed demo [--randomized] [--quiet]
npm run season -- --all          # time all three seasons
npm run parity -- --season 2026 --n 20   # who wins events/Champs across many seeds
npm run dev          # UI dev server
```

`--phase` is `champs`, `major:<stage>`, `minor:<stage>` or `quals:<stage>:<week>` and selects the map pool.

Browser tests: `npm run e2e` builds the site and runs Playwright (Chromium) against it (`e2e/`). `e2e/visual.spec.ts` compares screenshots of a fixed season (a share link with a seed) with committed baselines per platform; a missing baseline is written on first run. CI skips them until Linux baselines exist: run the **Visual baselines** workflow (Actions tab) to generate and commit them, and again after an intended look change. The first time, run `npx playwright install chromium`. CI (`.github/workflows/ci.yml`) runs the type check, the unit tests and the browser tests on every push and pull request; the Pages deploy still runs the unit tests before publishing.

The site installs as an app and works offline after the first visit (`public/manifest.webmanifest`, `public/sw.js`; icons from `scripts/make-icons.ts`).


## Simulation

- `src/engine/rng.ts`: seeded RNG. `fork(label)` gives independent streams, so the same seed always replays the same season.
- `src/engine/sim/arena.ts`: the gunfight core. Every kill, death and damage number comes from a duel.
- `src/engine/sim/modes/*`: Hardpoint (hill by hill), SnD (round by round: plants, defuses, clutches), Control (rounds with a 30-life pool), Overload (possessions, halves, sudden death).
- `src/engine/sim/boxscore.ts`: box scores and map scores are recomputed from events only.
- `src/engine/sim/veto.ts`: runs any `data/veto.json` procedure. Teams decide through a `Chooser`: the AI by default, or the UI in GM mode.
- `src/engine/sim/tuning.ts`: every calibration knob.

## UI (`npm run dev`, then open http://localhost:5173)

- **Saves:** your season autosaves in the browser (IndexedDB) after every change and comes back when you reopen the site. **Saves** has six named slots shown as cards, plus Export/Import file for backups or moving between browsers. Saves drop map event logs because matches replay exactly from the seed.
- **Archive and Hall of Fame:** every season you finish is kept automatically (Saves → Archive) with its champion, final, Champs MVP, event winners and, in GM mode, your finish; open any of them again. The Hall of Fame totals titles, Champs MVPs and GM careers across every save in the browser.
- **Share:** copies a link with the season, seed and settings (and, in Commissioner mode, how far it's been simmed). Opening it rebuilds the exact same season. GM decisions aren't in the link, so a GM link starts that season fresh.
- **Theme:** ◐ cycles auto, light and dark; ◑ toggles high contrast. Both are remembered per browser.
- **Odds:** simulates the rest of the season 50, 100 or 250 times from where it stands (in the background worker) and shows each team's chance to win Champs, make Champs and win a Major, plus average points and rank. Played results stay fixed, and it waits while a result is unwatched. For the real seasons, **Real vs sim** lists each Major and Champs with its real winner, the sim's chance for that team, and the sim's favourite (real placements in `data/results/{year}.events.json`, from `scripts/make-real-events.ts`).
- **Compare:** two players (ratings, K/D overall and by mode, series win rate, age) or two teams (points, rank, series and map win rates, win rate by mode, lineup strength, head to head) side by side, with the better number in each row marked.
- **Records:** head-to-head between any two teams, the biggest upsets (wins over teams four or more places higher on preseason roster strength), the best single maps, the longest win streaks and the most sweeps.
- **Team pages:** click a team name (standings, the points table, match headers, records, odds) for its record, lineup and former players, map records, roster strength by stage and results.
- **About:** data sources, how ratings work, what's verified and what's approximate, and a changelog.
- **Phones:** the layout stacks under 640px wide, with no sideways page scrolling. Wide tables scroll inside their card.
- **Player roles** (About → Player roles): the wiki has no AR/SMG field, so everyone starts as flex. Label players here; the labels are saved in this browser and used by GM mode's role balance. **Export** gives JSON to send in so they can go into `data/roles.json` for everyone.
- **Keyboard and accessibility:** arrow keys (and Home/End) move between tabs and segmented toggles. In the map editor, `]` and `[` pick the next or previous item, arrows move it (Shift for 5 units, Alt to resize) and Delete removes it. Charts carry text labels for screen readers, focus outlines show for keyboard users, and with reduced motion on, animations stop and the 3D replay starts on the still overhead camera.
- **Header:** the season line, then the status line with Sim week, Sim stage and Sim season. **New season** opens the setup panel: game, seed, Commissioner or GM (and team), Historical/Randomized ratings, Full season or Champs only, and Chaos. **Save** and **Load** export and import the whole season as JSON. **Chaos** gives every team a hot-or-cold form swing each weekend (event or qualifier week), so upsets and surprise runs are far more common; it's saved with the season and stays reproducible from the seed. **Champs only** skips the regular season and plays Champs from that year's real seeds (2026 also starts from the real final points). **Real form** (Historical ratings only) plays each event with every player as hot or cold as they really were there: their K/D at that event against their season K/D, from `data/stats/{year}.form.json`, shrunk for few maps and capped at ±0.04 skill. It uses the real results, so it's for replaying a season, not forecasting one (in the backtest it lifts the 2026 placement correlation from 0.79 to 0.87).
- **Watchlist:** every match on the Schedule that hasn't been played has a **Watch** button. Events have **Watch final** and **Watch all**. Simming plays everything else instantly, but a watched match keeps its result hidden everywhere (standings, points, brackets, and bracket matches that depend on it) and the sim stops with a "Ready to watch" banner. Watching plays the series map by map, with future maps shown as "—". You can also skip to the result, or skip them all.
- **Schedule:** stage by stage, week by week, with the map pool for each week; Minors and Majors appear inline with their real results for comparison.
- **Standings:** the CDL points table (Champs cut line) and each stage's qualifier table, using the season's tiebreakers.
- **Brackets:** every Minor, Major and Champs, including play-ins and Pro-Am groups, plus placements and points awarded.
- **Match page:** veto board, map cards, per-map and series box scores, play-by-play, and Watch (play/pause on the game clock at 1×/4×/16×/64×, next beat, scrubber, live kill feed). Online matches have no stored log; opening one replays it exactly from the seed.
- **Highlights and commentary** (`src/engine/sim/highlights.ts`): each map's best moments (clutches, triples and quads within 10 seconds, defuses, Overload scores, hills broken off the other team) appear as chips once playback reaches them. Click one to replay it, or **Highlight reel** plays them back to back at 1× with the 3D camera following the player. **Commentary** shows a caster line over the view for first bloods, plants, defuses, clutches, multi-kills, hill and round results, map point and halves.
- **Round strip:** SnD and Control replays show each round as a chip (who won, and how: elimination, detonation, defuse or time; ★ for a clutch). Click one to jump to that round. Only rounds already reached are shown.
- **Recap:** every finished match opens with a short written recap: the result (sweep, comeback or straight win), the deciding map if it went the distance, the series' best K/D, and its best moment.
- **Clip links:** in Commissioner seasons, **Share this moment** in a replay copies a link that opens the same season, match and map, paused at that second.
- **Watch party:** **Watch party** on a bracket plays every match of the event in order, each revealed map by map like a live match, with a progress strip that fills in results as you go. After each series, the next one starts in 5 seconds (or press **Next match**; turn off **Auto-continue** to stop).
- **3D replay** (Watch → 3D; "Feed only" turns it off, remembered per browser): the map as a blockout with all eight players, driven by the same event log as the feed. Hills light up in the holding team's colour, the bomb appears on the planted site, Control zones fill as they're taken, and the Overload device rides with its carrier; kills draw a tracer and leave a marker. Players are steered so they're in the right place when each event happens (the planter on the site, hill holders on the hill, the scorer at the goal, killer and victim near each other), with seeded movement so a map always plays back the same way. It only ever draws up to the playback clock, so it's safe on spoiler-free match day. Drag to orbit, scroll to zoom; "Follow action" tracks the objective. three.js is loaded only when the 3D view opens.
  - **Layouts** (`src/ui/replay/maps-bo7.ts`, `maps-bo6.ts`, `maps-mw3.ts`): every map in all three seasons' pools is traced by eye from the GamesAtlas minimaps and rotation diagrams, with hills in the published rotation order (MWIII diagrams mark hills with pins, so those use the pin tips; 6 Star has no published diagram, so its hills are guesses from their names). Bomb sites, Control zones and Overload goals aren't published there, so they're placed by eye and approximate; Control maps without their own zones reuse two hill spots. A map outside the pools gets a generated stand-in arena, labelled as such. Tests check that every spawn and objective sits on open ground and can be reached, and that every pool map has a spot for each hill. Movement comes from `src/ui/replay/timeline.ts` (pure, tested in `tests/replay.test.ts`).
  - **Views:** Watch switches between **3D**, **2D** (a top-down minimap view, light on phones) and **Feed only**. In 3D, the camera can be Broadcast (follows the objective), Auto-cut (cuts to each fight), Follow player, Overhead or Free. There's also a 2D **minimap** inset, a broadcast-style **kill feed**, and **callouts** (area names from the hill names and any the layout adds).
  - **Geometry:** layouts can have **buildings** (walls with doorways and see-over windows; Rewind's store, Vault's bank and Sub Base's hangar), **upper floors** players stand on (Den's balcony, Colossus's overlook), and a **colour theme** per map. Players **hold spots behind cover** that can see the objective: these are found automatically for every map, plus any power positions the layout marks.
- **Maps tab:**
  - **Real map data:** each map's pace and closeness from real results, and for SnD (where the wiki has full plant records, which is 2026) the plant rate and retake (defuse per plant) rate.
  - **Heatmaps:** where players die, or where kills come from, on any map this season, for all teams or one. Built from the replays in the background worker.
  - **Map editor:** pick a map, lay your own reference image under it (it stays on your computer), and move, add or resize walls, buildings (with doors and windows), upper floors, floor areas, hills, bomb sites, Control zones, Overload goals, spawns, hold spots and callouts. **Check** runs the same open-ground and reachability test the code uses. **Save to this browser** makes every replay use your version straight away; **Export JSON** gives the file to send in so it can be built into the site for everyone.
- **Summary:** champion and Champs MVP vs the real result, points race chart (up to 3 highlighted teams), event winners, K/D leaders, and a cumulative points table.
- **What if** (Summary tab, Commissioner seasons; `src/engine/season/whatif.ts`): pick a Major or Champs and a team. Everything before that event replays exactly; the event is re-rolled (up to 400 times) until that team wins it, then the rest of the season plays on with the new luck. A table compares final points with this season, and **Play this timeline** switches to it. Leave the team on "anyone" to just re-roll the event.
- **Player career:** player pages show a **Real career** table across 2024–2026 (team, real age, rating, maps, K/D), and each season opens to event-by-event K/D, from the CoD Esports Wiki.

## GM mode

Choose **GM** in the header, pick a team, then start a new season.

- **My Team:** set your four starters from a 4–6 player roster, and see ratings, results and your move log. "Auto-veto my matches" hands your vetoes to the AI.
- **Roster moves:** sign and release only in preseason and between stages (after a Major, before the next stage's qualifiers). Free agents are every player in the season's data who isn't starting for another team on the next match date. If you sign a player an AI team would field later, that team plays its next available player, or a replacement-level one (72 across the board).
- **Negotiation** (`src/engine/gm/negotiation.ts`): **Negotiate** on a free agent lets you set salary, length, a signing bonus and a team option. Players take up to 12% less to join the strongest roster, value a bonus at 1.25× the same money as salary, and want 5% more for a team option. A low offer gets a counter you can meet. The bonus is paid now and counts against this season's cap.
- **Personalities** (`src/engine/gm/personality.ts`): about 40% of players have a trait, fixed per player: **Leader** (+1 morale a week to each other starter while starting), **Hothead** (morale swings ×1.5), **Steady** (×0.6), **Mercenary** (asks 10% more, half the contender discount) or **Loyal** (10% less to re-sign with you). Shown on player pages and My Team.
- **Sponsors** (`src/engine/gm/sponsors.ts`, Staff tab): pick one deal before your first match: Steady ($60k), Performance ($15k plus $20k per Major top 4 and $40k for a Champs top 3) or Fan engagement ($20k plus $3k per series win). The money goes on top of the $200k staff budget.
- **Cap table** (Market tab): the next three seasons of salaries, team options and dead money, with room under the cap.
- **Extra rules** (New season → GM; not in the real CDL, off by default): **Rookie draft**, a one-round draft of the new Challengers class each off-season with the worst team picking first (your pick joins the academy; pick in the off-season panel), and **Coach timeouts**, one per series between maps (with Pause between maps on) for +0.015 skill on the next map.
- **Scouting fog** (`src/engine/gm/fog.ts`, on by default; toggle on My Team): other teams' ratings show as ranges, 12 points wide with no analyst. Each analyst star takes 2 off, each map played against them 0.5, and a scrim with their team 3. Your own players and prospects are always exact. Ranges show on the free-agent list, player pages, trades and Compare.
- **Vetoes:** when the sim reaches one of your series it stops (mid-week or mid-bracket) and opens the veto screen:
  1. Lock in a lineup, and choose Team A or B if you're the higher seed.
  2. Answer your bans, picks and sides while the opponent's AI answers instantly ("AI finish" completes the rest).
  3. Play the series. The sim then carries on with the week, stage or season you started.
- **Spoiler-free match day** (on by default; toggle on My Team): when your series has been played, sims stop and a Match Day banner offers **Watch** or **Skip to result**. Watching plays the series map by map: the series score, map cards (future and unplayed maps both show "—"), box scores and play-by-play only show what has happened so far. Until you watch or skip, standings, points, the points chart, brackets (including matches that depend on yours), the schedule, the summary and My Team all leave your result out (`src/ui/spoilers.ts`).
- **Sub swaps:** turn on "Pause between maps" (My Team or the veto screen). Your series then stops after each map, showing the series score and each player's K–D so far. Pick the next map's four from your whole roster (sign a 5th or 6th player between stages for a bench), or play the rest of the series with that lineup. This needs manual vetoes; auto-veto never pauses.
- **Determinism:** each series stores its lineups (per map, including sub swaps), your veto answers and your prep/morale boost, so GM seasons replay exactly and save/load mid-season.

### The front office (`src/engine/gm/`, Office tab)

- **Difficulty** (picked at New season): Easy (bigger cap, friendlier trades, patient owner), Normal, Hard (tighter cap, tougher AI, impatient owner, bigger morale drops) and Sandbox (no cap, can't be fired).
- **Chemistry:** every pair of players builds chemistry with each map they play together; real teammates start partway and new arrivals start at zero. Full chemistry is worth +0.01 skill and none costs −0.01.
- **Role balance:** a starting four needs an AR and an SMG player (flex covers either), or it takes a −0.012 form penalty. My Team shows both as you pick the lineup.
- **AI teams that move:** AI teams sometimes trade with each other when a window opens. Past the real seasons, AI players aged 32 and over retire and are replaced from free agency each off-season. Every AI move is stored as who arrived and who left (`aiPatches`), so the team still follows its real roster changes on their real dates around it.
- **Achievements:** twelve milestones that carry through a dynasty, such as a reverse sweep, a perfect stage, beating the favourite, winning Champs, or an academy graduate winning an award.
- **Season review:** at season's end the Office shows your finish, record, titles, best win, worst loss, top performer, event finishes and awards, with a downloadable share-card image.
- **Career** (Office tab): totals across the dynasty, owner verdicts, achievements, season by season, best signings and awards won.
- A **Getting started** guide on the Office Overview (dismissable), and **?** tooltips on the Office numbers.

The Office has sub-tabs: **Overview** (inbox and goals, plus the off-season when a season ends), **This week** (scouting, prep and the practice planner), **Calendar**, **Market** (offers, contracts, trades), **Staff**, **Academy** and **Awards** and **Career**.

- **Calendar:** every step with its date, your qualifier matches (with results once watched, 🔥 for rivals), and the windows. Signing and trade windows open before the season and after each Major. The window before Champs is signings only, which is the **trade deadline**.
- **Storylines:** win and loss streaks make the news. Rivalries heat up each time you meet a team (more for close series and losses), and some real ones start warm (OpTic and FaZe, for example). Rivalry results swing morale ±2. After Majors, Champs, rivalry games and streaks you get a **press conference** with three answers: back the players (+3 morale), stay humble (+2 owner trust), or call out the opponent (+5 morale for starters, −2 trust, rivalry heats up).
- **Staff:** hire a head coach and an analyst (1–5 stars) from a seeded pool. They're paid from a $200k staff budget that also covers the academy. The coach scales prep bonuses (×0.7 at one star to ×1.3 at five), softens morale losses and speeds up academy growth. The analyst decides how much scouting you get: none means your own map numbers only, 1–2★ adds the opponent's likely picks and bans, and 3★+ shows their map numbers and exact prospect potential. The analyst also adds a small game-plan edge. You start with a two-star coach and no analyst.
- **AI market:** each time a window opens, AI teams with holes (players you signed or traded for) sign the best free agents. AI teams also send trade offers for your players; offers target your trade block first and expire when the window closes. Underpaid players ask for raises (pay it or lose morale), and very unhappy players ask for a trade (talk it out, or put them on the block). Answer all of these in the inbox or on the Market tab.
- **Challengers academy:** twelve generated prospects each season, aged 17–20 with a hidden potential. Sign up to three ($15k each); they grow toward their potential every step, and faster with a better coach. Promote them to the main roster between stages on a two-year minimum deal, where they play like anyone else. Academy players carry into the next dynasty season a year older.
- **Awards:** after Champs come MVP and Rookie of the Year (scored on K/D and map win rate), Champs MVP, and All-CDL first and second teams. Winners ask for more money (MVP +20%, All-CDL +5–10%), and your winners get +8 morale. The Awards tab also tracks the MVP race all season.
- **Practice planner:** scrim up to two teams a week. A scrim gives full scouting intel on that team and a +1.2 edge against them in the next two steps, but adds 12 fatigue. Prep adds or clears fatigue too, and Rest clears the most. Over 50 fatigue costs form on every map.

- **Scouting:** your next opponent's record, recent form, lineup (overall and K/D, with their hottest player), the roster edge, and every map in the week's pool with both teams' map preferences and their likely picks and bans. Unwatched results are left out.
- **Weekly prep:** Balanced, Map focus (+0.04 skill on one map), Mode focus (+0.02 on every map of a mode), Rest (+4 morale) or Grind scrims (+0.015 everywhere, −3 morale). Prep is hidden from the opponent's veto; it only changes how the maps play. For scale, team map preferences from real win rates run about ±0.05.
- **Morale** (0–100, 70 neutral): wins and losses move it (more at Majors and Champs), so do personal K/D, sitting on the bench and prep, and it drifts back toward 70 each step. It adds or costs up to ±0.025 skill per player. Unhappy players say so in the inbox.
- **Inbox:** recaps of your matches, a league roundup each week, event results, owner notes, and trade and contract news. Anything that would give away an unwatched result waits until you've watched; morale and owner trust do too.
- **Player pages:** click any player name (My Team, box scores, scouting, leaders) for ratings, age, contract, morale, the season by mode with mode stats, and a series log.
- **Owner goals:** set before the season from where your roster ranks in strength, such as "Win a Major", "Finish top 4 in CDL points" or "Qualify for Champs". Owner trust (0–100) moves after every Major and Champs against that expectation. The end-of-season verdict depends on goals met: contract extended, satisfied, on notice, or fired (fired needs low trust).
- **Contracts and the cap:** every player has a salary ($k a season) and years left. Asking salaries run from about $40k at 70 overall to $300k at 92; one-year deals cost 10% more, three-year deals 5% less. Payroll must stay under the $1,100k cap to sign anyone asking more than $60k. Releasing a player leaves half their salary on the books for the rest of the season.
- **Trade counter-offers:** when an offer is short on value, the AI team says what it would take instead: the same deal plus your least valuable player that makes it work, or the same deal minus one of theirs. **Use their counter** fills it in.
- **Extensions** (Market → Contracts): extend a player before their deal runs out, for longer than they have left. The price is a re-signing price (rating, contender discount, mood) with current form on top: hot players ask 8% more, cold ones take 8% less. Players under 45 morale won't talk, and an extension gives +4 morale.
- **In-season growth** (`src/engine/gm/development.ts`): after each Major, your players aged 21 and under gain about 0.8 rating points and those 22–23 about 0.4, scaled by your coach, with some luck. The inbox lists the gains.
- **Challengers events:** after each Major your academy prospects play a 16-team Challengers event. Placing comes from their rating plus luck; a top-two finish adds +1.2 growth and top four +0.6. Results show in the inbox and on the Academy tab.
- **Trades:** in the same windows as signings, offer players to any AI team. They accept when they come out at least 10% ahead on trade value (30% if you want their best player), and you can't take on salary over the cap. Traded players switch teams for the rest of the season; nobody can play for two teams.
- **Dynasty:** when a season ends, the Office shows the off-season. Re-sign expiring players (or let them go, or **use the team option** to keep them a season at the same salary). **Free agency:** see the best 24 free agents of the coming season and make offers; the best ones draw bids from up to three AI teams, and each player signs where the money looks best, with up to 15% extra pull for a stronger roster. Results go to the inbox. Then confirm which team your franchise becomes next season (renames such as Seattle Surge → Vancouver Surge are followed), and start the next season. Players with years left come with you, one year off each contract. Morale and owner trust carry over, and a dynasty history table records each season. The real seasons run 2024 → 2025 → 2026 with other teams on their real rosters. After that the 2026 format repeats as CDL 2027, 2028 and on, with every player's ratings progressing by age each off-season. Ages are real, from CoD Esports Wiki birthdates (`data/stats/players.json`, via `scripts/fetch-roles.ts`; 104 of the 114 players), counted on 1 March of each season's year. The few without one get a seeded age. Real results aren't shown for those seasons, and dates still show the 2026 calendar.

Engine API (`src/engine/season/season.ts`): `advance` returns `undefined` and sets `state.pending` at a GM series. `gmVetoSession` starts the interactive veto (a `VetoSession` that only waits on your decisions) and `submitGmVeto` stores it. The next `advance` resumes the step. Roster functions: `gmSign`, `gmSignOffer` (negotiated terms), `gmRelease`, `gmSetStarters`, `gmSetAutoVeto`, `freeAgents`, `gmCanMakeMoves`.

## Season pipeline

- `src/engine/season/schedule.ts`: seeded round-robin slices; every team plays exactly the stage's match count with no repeat opponents.
- `src/engine/season/standings.ts`: standings with the season's tiebreaker order. Head-to-head counts only games among the teams still tied; a seeded coin flip is the last resort.
- `src/engine/season/bracket.ts`: every format is a list of match definitions (slots point at a seed or at the winner/loser of an earlier match). It covers the 12-team double elimination (seeds 9–12 start in Losers R1), the 8-team Champs bracket, Minors (12-team single elimination with 4 byes), the 2026 Major II play-in, and the 2026 Pro-Am GSL groups feeding the playoff.
- `src/engine/season/season.ts`: `SeasonState` is plain JSON, so save/load is `JSON.stringify`/`parse`. `advance` runs one step (a qualifier week or an event), `advanceStage` runs to the next Major, `advanceSeason` runs to the end. Full event logs are kept for LAN events and the GM team; any other series is rebuilt exactly with `replaySeries`.

### Bracket rules, checked against Liquipedia brackets

The pages are in `data/sources/liquipedia/` (CC BY-SA).

- **12-team Majors:** Winners R1 is 1v8, 4v5, 2v7, 3v6 (2024 Majors I and IV, 2025 Majors II and IV). In Losers R1 the 1v8 loser plays seed 9, 4v5 plays 12, 2v7 plays 10 and 3v6 plays 11. Losers R2, the crosswise drop of the Winners semifinal losers, and the rest of the lower bracket match the real brackets. 2025 Major I is the one exception (its listed seeds pair 3v4 and 5v6), most likely a quirk in how its seeds are listed.
- **2026 Major II play-in:** 7v10 and 8v9 (Carolina–Paris, Toronto–Vancouver). Seed 1 meets the 8v9 winner and seed 2 the 7v10 winner.
- **2026 Pro-Am Major III:** the snake draw (A = 1/8/9/guest, B = 2/7/10/guest, C = 3/6/11/guest, D = 4/5/12/guest), GSL opening matches and the playoff pairing (group winner vs another group's runner-up: A1–B2, D1–C2, B1–A2, C1–D2) all match the real event.
- **Bo9 Grand Final:** mode order, map 9 = SnD, and the number of maps used per mode in the 2026 final all fit our Bo9 veto. Who picked what isn't recorded, so the exact order stays unverified.
- **Still unverified:** the tiebreak for equal CDL points (season series wins, then map differential).

## Player ratings and where they come from

- **Stats source:** the Call of Duty Esports Wiki's Cargo table `PlayerStats` (one row per player per map), downloaded by `npx tsx scripts/fetch-stats.ts` into `data/stats/{year}.raw.json`. The script makes two aggregate queries per season, spaced out and backing off on rate limits. The content is **CC BY-SA 3.0** (cod-esports.fandom.com contributors). Attribution is kept in each file, and derived files fall under the same license.
- **Breaking Point isn't used:** its terms say all use of its content requires written consent, and its API is by request.
- **Stat-based ratings:** `scripts/stat-ratings.ts` standardizes each stat against the season's regulars (15+ maps) and shrinks small samples toward average.

  | Rating | Built from |
  |---|---|
  | slaying | overall K/D |
  | hp_obj | Hardpoint K/D 65% + hill time per map 35% |
  | snd_iq | SnD K/D 50% + net opening kills 30% + plants/defuses 20% (where tracked) |
  | third_mode | Control or Overload K/D 75% + captures 25% |
  | clutch | a mild SnD K/D proxy (no clutch stat is published) |
  | consistency | map-to-map spread of kills minus deaths, per mode, relative to that mode's typical spread (`data/stats/{year}.consistency.json`) |

- **Team results blend:** each rating is 70% stat-based and 30% from team placements, so a good slayer on a losing team isn't over-rated.
- **Map modifiers:** each team's win rate on a map relative to its average in that mode, shrunk for small samples and capped at ±0.03 skill. The AI veto uses them, and so does the sim.
- **Lineup timelines:** a team gets a snapshot from each stage's qualifiers (its four most-played players there, from `data/stats/{year}.lineups.json`) and from each Major/Champs participant list (dated from the event). This catches changes at events a team missed; for example, 2026 Cloud9 switched lineups for Stage 2, but missed the 10-team Major II.
- **Rebuilding rosters:** `npx tsx scripts/build-rosters.ts` reads the committed event pages in `data/sources/fandom/` plus the stats. Players who only appear in qualifier stats join their team's bench. Each player records `ratingSource` (`stats` or `placeholder`) and a stat line, which My Team shows as K/D with "est." for placeholders.

## Map-specific numbers

`data/stats/{year}.maps.json` (from `scripts/fetch-mapstats.ts`, CoD Esports Wiki `PlayerStats`, split by winners and losers) gives each map's **pace** (kills per player per map) and **closeness** (the losing team's share of the winner's Hardpoint time, Control captures or SnD kills), relative to the mode average. Both are shrunk toward average for maps with few games. Pace scales how many kills each fight produces, so fast maps like Scar and Vault Hardpoint have busier box scores than Skidrow. Closeness can scale catch-up per map, but it's off by default: in the 200-run backtest it didn't improve event or scoreline accuracy. Both settings live in `TUNING.mapEffects`.

**Fight share** (`data/stats/{year}.fights.json`, `src/engine/data/fights.ts`): each player's real Hardpoint kills plus deaths per map, against the league average (shrunk for few maps). Who takes the next gunfight scales with it squared (`TUNING.fightShareExp: 2`), so entry players fight more and anchors less. The wiki has no AR/SMG labels, and fight volume alone doesn't separate them reliably, so this stands in for roles. With it, the sim's per-player fight rate correlates 0.67 with the real one (0 before) with the same spread, and mean event log loss across the three seasons went from 1.514 to 1.462.

**Series scorelines and map share** (backtest): real Bo5s end 3–0 about 34–40% of the time against the sim's 27–30%, and the sim's teams are more even than real ones in Hardpoint and the third mode (spread ratio 0.6–0.75; SnD is about right). Steeper per-mode skill curves (`modeDuelScale` 1.3–2.0 for HP, Control and Overload), less catch-up, and a per-series form swing (`seriesFormSd`) were all tried at 200 runs: series form at 0.03 halves the series scoreline gap but worsens event log loss from 1.46 to 1.63, and steeper curves make individual map scores too lopsided. None beat the current settings, so they stay. How often each map is played per mode already matches real play within about 7%, so the AI veto is left as it is.

**Tried and left off:** LAN fatigue (`TUNING.lanFatigue`, form lost per series past the third at a Major or Champs) made 2024 noticeably worse (log loss 1.49 → 1.68) at 0.01 and 0.02. A sweep of `duelK`, `engageK`, `manAdvantage` and Hardpoint catch-up around their current values, with fight share on, found nothing better than the current settings.

`data/stats/{year}.snd.json` adds SnD plants and defuses per map. The 2024 and 2025 records are too incomplete (under a plant a game), so only maps with two or more plants a game count, which in practice means 2026. Plant rate scales the chance to plant and retake rate scales the post-plant edge, behind `TUNING.mapEffects.snd`. It's **off**: at 200 runs on 2026 it nudged points accuracy up (MAE 43.0 → 42.1) and event-winner accuracy down (real winner's chance 18.3% → 16.7%).

SnD plants can't happen before 15 seconds into a round (`TUNING.snd.minPlantSecs`). The engine used to log some at 0:00. An early plant now lands at 15 seconds instead, and because the bomb timer runs from the plant, results are the same as before.

## Backtest

`npm run backtest -- --n 200` simulates each season 200 times with Historical ratings, compares the results with what really happened, and writes [docs/backtest.md](docs/backtest.md). It checks:

- **Event winners:** the win probability the sim gives each real Major/Champs winner, and the rank correlation of placements.
- **Team strength:** each team's real map win % per mode against the simulated one: correlation, plus spread with the real data's sampling noise removed.
- **Scorelines:** real map score distributions from the committed Liquipedia pages, compared with simulated ones.
- **CDL points:** real points rebuilt from the series results (`npx tsx scripts/fetch-results.ts`) and real Major placements.

`--tune key=value,...` overrides any `TUNING` value for a sweep, for example `--tune duelK=2.4,modeDuelScale.snd=2,overload.gapSecs=6:10`. The current `duelK`, `modeDuelScale`, `catchUp` and Overload pacing were chosen this way.

Per-event form (`eventFormSd`, a seeded hot/cold value per team for each qualifier week and event) was tested at 200 seeds and left **off**. At 0.025 it lifts the real 2026 upsets (Paris's Major I win goes from 2.5% to about 10%), but mean event log loss gets worse, from 1.60 to 1.66. That's because the 2025 favorites mostly did win, and form also flattens team spread. The UI's **Chaos** toggle turns it on per season at a stronger 0.04 (`chaosFormSd`), for upset-heavy seasons.

Overload note: the real 2026 map scores have 4–3 and 3–2 as the most common results, as the original brief said. But nearly half of the winners scored 5 or more, so the sim now produces more captures per map than the brief's "winner on 2–5" target.

## Data notes

- **Hardpoint hill rotations:** each season file has `hardpointHills` (hill count, names in order, and a source per map). The log and Watch mode show them, e.g. "Hill 3 (P3 Stairwell)". Loading fails if any Hardpoint map in a pool lacks a rotation. The rotations come from public map guides and patch notes, with gaps noted in each season's `unverified` list. Every hill plays the same in the sim; the rotation sets the hill count and names.

- Every JSON file is validated on load. Bad data throws a `DataError` listing every problem.
- Veto bans are skipped when they would leave a mode with fewer maps than the series needs (`skipBanIfInsufficient`). This handles 2025's two-map Control pool and the Bo9 SnD maps without special cases.
- Player ratings come from season stats where available (see above). Roles default to `flex`: the stats don't say who plays AR or SMG.
